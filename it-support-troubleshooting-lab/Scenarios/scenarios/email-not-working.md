# Scenario 5: Email Not Working (Outlook Issue)

## Problem
User reports that they are unable to send or receive emails in Outlook.

## Possible Causes
- No internet connection
- Incorrect login credentials
- Mailbox not syncing
- Outlook profile corruption
- Microsoft 365 service issue
- Full mailbox storage

## Troubleshooting Steps
1. Check internet connection
2. Verify user login credentials
3. Restart Outlook application
4. Check if Outlook is in “Work Offline” mode
5. Clear Outlook cache and restart
6. Recreate Outlook profile if issue persists
7. Check Microsoft 365 service status

## Outcome
Issue resolved after restarting Outlook and re-syncing the mailbox profile.
