# Scenario 4: Printer Not Working

## Problem
User reports that they are unable to print documents from their computer.

## Possible Causes
- Printer is turned off or disconnected
- Paper jam or low ink/toner
- Printer is set to offline mode
- Incorrect default printer selected
- Driver issue

## Troubleshooting Steps
1. Check if the printer is powered on and connected properly
2. Verify paper tray and ink/toner levels
3. Check printer status (Online/Offline)
4. Set correct printer as default
5. Restart printer and computer
6. Reinstall or update printer drivers if required

## Outcome
Printing issue resolved after setting the correct printer as default and clearing offline status.
