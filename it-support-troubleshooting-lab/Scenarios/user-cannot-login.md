# Scenario 3: User Cannot Log In

## Problem
User reports that they are unable to log in to their computer or system.

## Possible Causes
- Incorrect username or password
- Account locked due to multiple failed attempts
- Password expired
- Active Directory account disabled
- Network connectivity issue (domain login)

## Troubleshooting Steps
1. Verify username and password with the user
2. Check if Caps Lock is enabled
3. Attempt login with correct credentials
4. Check Active Directory to confirm if account is locked or disabled
5. Unlock or reset password if required
6. Ensure system is connected to the network/domain
7. Ask user to try logging in again

## Outcome
User was able to log in after the account was unlocked and password reset.
